# Hard dependencies for this paper repo on Linux GPU.
# Recommended baseline: Python 3.10 (aligned with HZWDP: Python 3.10.20).
#
# Install in two steps:
# 1. Preinstall a CUDA-matched torch stack for your machine:
#      torch, torch-geometric, torch-sparse
#    Use PyTorch wheels plus the PyG extension wheels from:
#      https://data.pyg.org/
#    `torch_sparse` must match both your installed torch version and CUDA build.
# 2. Then run:
#      pip install -r requirements.txt
#
# HZWDP reference core stack:
#   torch==2.8.0+cu128
#   torch-geometric==2.8.0
#   torch-sparse==0.6.18+pt28cu128
#
# We intentionally do not pin local wheel suffixes such as `+cu128` here.
# The install contract is to preinstall the CUDA-specific wheels first, while
# this file keeps the project on the same ABI / major-version family as HZWDP.
#
# Not included here because they are optional, not hard dependencies:
#   wandb        -> only needed for `--log`
#   matplotlib   -> only needed for `--collect-grad-stats` plotting
#   seaborn      -> not imported by the repo
#   scikit-learn -> only used by deepwalk example scripts
#   psutil       -> only used by deepwalk's standalone CLI entrypoint
